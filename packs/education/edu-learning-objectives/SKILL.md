# Learning objectives

Turn a topic into objectives a teacher can teach and assess. Every other skill in this kit starts from these.

## Ask first

Get these before writing. If the teacher skips one, state the assumption you made.

1. Grade and subject.
2. Topic or text.
3. Standards, if the school uses them. Accept any framework: Common Core, NGSS, a state or national curriculum, or the teacher's own goals.
4. Time available: one lesson or a whole unit.

## Write the objectives

1. Start each objective with one observable verb: "explain", "compare", "solve", "write". Avoid "understand", "know", and "learn", because you can't see them.
2. Name the content and, when it helps, the condition: "Solve two-step equations with integer coefficients without a calculator."
3. Tag each objective with a cognitive level. Use Bloom's revised taxonomy (remember, understand, apply, analyze, evaluate, create) or Webb's Depth of Knowledge (DOK 1 to 4). Use the one the teacher's school uses. Default to DOK.
4. Write 1 to 3 objectives for a lesson and 3 to 6 for a unit. More than that and nothing gets taught well.
5. Add success criteria under each objective: 2 to 4 student-facing "I can" statements that describe what good work looks like.

## Align to standards

- Put each standard code the teacher gave you next to the objectives it supports.
- If an objective has no standard, leave it unaligned and say so. Don't stretch a code to fit.
- If the teacher gave no codes, write `[standard: ask teacher]` and keep going.

## Output

A table with columns: objective, level (Bloom's or DOK), success criteria, standard. Follow it with one line on which objective is the priority if time runs short.

## Guardrails

- Standards: use only the codes the teacher gives you. If there are none, write `[standard: ask teacher]`. Never invent a code or quote standard text from memory.
- Privacy: work without student names or identifying details. If the teacher pastes them, replace them with "Student A" or initials and say that you did. Ask for the accommodation a student needs, not for the IEP or 504 document.
- Age and safety: fit reading level, content, and examples to the grade. Flag sensitive topics, lab or physical safety, and anything the school may need to approve.
- Accuracy: work every answer key yourself. Mark any fact you are not sure of with `[verify]`.
- The teacher decides: you draft. Grades, placements, and IEP services are the teacher's and the school's call.
