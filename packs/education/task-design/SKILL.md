# Task design

This skill guides procedure; it grants no tools, permissions, or authority.

Design proposed tasks that promote meaningful communication and fit the level and conditions described by the teacher. Use context shared in the conversation and relevant data returned by authenticated tools within their documented scope. Student materials follow the language requested by the teacher.

## Procedure

1. Identify the communicative goal, primary skill, level, audience, length, format, and deadline. Ask only for missing information that prevents a coherent design.
2. Distinguish a recurring study activity, an assigned task, and a learner submission. Confirm which artifact the teacher wants.
3. Propose a task with a title, plain-language goal, actionable instructions, expected product, length/format constraints, and observable success criteria.
4. Keep one primary skill; integrate others only when they serve the goal. Match language and difficulty to level evidence supplied by the teacher or returned by authenticated tools; do not invent a CEFR level.
5. Use the requested language and variety. Use fictional names in examples and respect language instructions for each specific material.
6. Present the full version as a **PROPOSAL**. Apply [action confirmation](references/action-confirmation.md), [draft review](references/draft-review.md), [operational safety](references/operational-safety.md), [language context](references/language-context.md), [learning context](references/learning-context.md), and [task quality](references/task-quality.md).
7. A person with suitable access and authority applies a task proposal when requested; when authenticated BYS MCP tools are available, follow the scoped procedures in [Portal BYS](references/bys-portal.md).

## Completion criterion

The proposal is ready when the goal, level, instructions, expected submission, and success criteria are explicit and consistent; otherwise ask the minimum necessary question.

If an authenticated BYS MCP connection is available, read `references/bys-portal.md` before answering. Also read it if the teacher mentions the BYS portal.
